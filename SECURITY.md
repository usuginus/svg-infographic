# Security

## Reporting a vulnerability

Please do not open a public issue. Use **Report a vulnerability** on the [Security tab](https://github.com/usuginus/svg-infographic/security) of this repository, which sends a private report to the maintainer.

Include what you did, what happened, and the files or commands needed to reproduce it.

## Scope

The skill runs a local headless browser on SVG files that Claude writes on your machine. Relevant reports include ways for SVG content to read local files, run scripts, or reach the network through `render()` or `check()`.

## Supported versions

Only the latest release receives fixes.
